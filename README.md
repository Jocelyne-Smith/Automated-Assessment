# msc-llm-webdev-assessment

Supporting material for the M.Sc. (Data Science) dissertation *Evaluating Large Language Models for Automated Assessment and Formative Feedback in Introductory Web Development Education* (Jocelyne Smith, University of the Free State, 2026).

## Contents

| Folder | Contents | Chapter |
|---|---|---|
| `module-guide/` | CSIS1664 module guide (© UFS, shared with permission) | 4 |
| `prompts/` | Grading and feedback prompts | 4 |
| `rubrics/` | Rubrics, memo and marking guidelines | 4 |
| `notebooks/` | Extraction, anonymisation, grading and evaluation notebooks | 4–5 |
| `results/` | Aggregate metrics, tables and figures | 5 |

## Data

Student submissions and marksheets are not included, in line with the study's ethics clearance and POPIA. Notebooks are shared with outputs cleared.
